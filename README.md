# Squire Components

Reusable public Squire components.

Install all components:

```bash
squire download AndreBaltazar8/squire-components
```

Install one component:

```bash
squire download AndreBaltazar8/squire-components#svelte
```

Components are YAML files under `components/`. Private project tools and local-only guidance should live in your own config directory, not this repo.
